## How it works

1. **Sign up** at [marketingcloud30.com](https://marketingcloud30.com/challenge/sql30/) and pick SQL30.
2. **Get one email a day** for 30 days, each with a short marketing scenario and a query to write.
3. **Run it against the sample data.** Import the day's CSV(s) as data extensions in your own Marketing Cloud org (Query Studio or a Query Activity), or load them into any SQL editor.
4. **Check your work** against the solution on the challenge page.

> This repo holds **only the sample datasets** you query to complete a day. The scenarios and step-by-step solutions live on the website - nothing here spoils the answer.

## What each day folder contains

Every `day-NN/` folder has a short `README.md` describing that day's focus and listing any files to download. Some days reuse a dataset from an earlier day; those folders have no new file and point you back to the day that introduced it.
