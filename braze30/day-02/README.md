# Day 2 - Set Up Email Subscription Groups

## English

Create Fenly's two email subscription groups and import each customer's choice into them.

**Files:**

- `weekly-menu-subscriptions.csv`: 111 rows for the Weekly Menu group
- `market-deals-subscriptions.csv`: 131 rows for the Market Deals group

Before importing, replace the placeholder in the `subscription_group_id` column with the ID of the group you created in Braze.
