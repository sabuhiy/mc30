# Day 30 - Capstone: Fenly+ Upgrade

## English

Bring the month together in one Canvas: a Catalog benefit for each plan, a 10% control group, a follow-up for shoppers who click and a profile update.

**Files:**

- `fenly_plus_benefits.csv`: 3 plans, 4 columns: id, plan_name, headline, member_discount. The id values (market, kitchen, both) match each customer's plan_type.

Upload it with Data Settings > Catalogs > Create new catalog > Upload CSV. Leave every column as String. The file name gives the Catalog the name fenly_plus_benefits.
